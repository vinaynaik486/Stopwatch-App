# ⏱️ Stopwatch App

A simple and responsive stopwatch application built using React. It allows users to start, stop, and reset time with precise millisecond tracking and a clean UI.

---

## 🚀 Features

* Start and stop the stopwatch
* Reset time instantly
* Real-time updates with millisecond precision

---

## 🛠️ Tech Stack

* React
* JavaScript
* Tailwind CSS

---

## ⚙️ How It Works

* Uses `useState` to manage time and running state
* Uses `useEffect` to handle intervals
* Updates time every 10ms for smooth tracking
